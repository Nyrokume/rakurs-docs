Перечень функций соответствует техническому заданию. Каждый пункт — проверяемое требование.

## Сбор на рабочем ПК

- Снимки экрана по интервалу и событиям из политики (FR-01).
- Размытие или пропуск окон из списка исключений **до сохранения** кадра (FR-02).
- Отбрасывание неизменившихся кадров: сравнение изменённых областей и перцептивный хэш (FR-03).
- Телеметрия: активное окно, простой, процессы, сеансы, подключения USB, сетевые соединения, установленное ПО, автозагрузка, выбранные ключи реестра, инвентаризация железа, состояние защиты (FR-04).
- Работа без сети не менее 7 дней: данные хранятся в зашифрованной очереди с квотой (FR-05).
- Применение подписанной политики с сервера без перезапуска (FR-06).
- Обновление по подписанному манифесту, кольцами, с откатом (FR-07).

## Прозрачность и согласие

- Значок в трее и окно с перечнем собираемых данных и последними снимками (FR-08).
- Данные, привязанные к человеку, не собираются, пока сервер не подтвердил ознакомление сотрудника (FR-09).
- Выгрузка данных сотрудника по его запросу, ст. 14 152-ФЗ (FR-18).

## Сервер

- Приём данных по gRPC с mTLS, подтверждение пакетов, отсутствие потерь при перезапуске (FR-10).
- Распознавание текста на снимках (OCR) и индексирование для поиска (FR-11).
- Автоматическое удаление данных по срокам хранения из политики (FR-16).
- Неизменяемый журнал всех действий в консоли, включая просмотр снимков (FR-15).

## Веб-консоль

- Лента дня, отчёты по времени и приложениям, инвентаризация, хронология инцидента, поиск по тексту с подсветкой области на снимке (FR-12).
- Редактор политик с проверкой схемы, версиями и сравнением (FR-13).
- Правила и оповещения по событиям (запуск ПО, USB, нерабочее время), пороги частоты и эскалация уровня, предупреждение сотруднику без блокировки (FR-14).

## Интеграции

- Active Directory (пользователи, группы, подразделения) и SIEM по syslog/CEF (FR-17).
