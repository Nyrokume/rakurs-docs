Чтобы было понятно, как это выглядит на практике, ниже — готовые примеры из типовой установки.

## Политика сбора

Политика задаёт, что, когда и сколько собирает агент. Вне рабочих часов данные, привязанные к человеку, не собираются; личные окна размываются до сохранения.

```yaml policy/sales.yaml
schedule:
  timezone: Asia/Yekaterinburg
  workHours:
    - days: [mon, tue, wed, thu, fri]
      from: "08:30"
      to: "18:00"

screenshots:
  enabled: true
  interval: 300s           # снимок раз в 5 минут
  triggers:
    windowSwitch: { enabled: true, minGap: 20s }
    usbInserted: true
  maxSide: 1920
  format: webp

privacy:
  blur:                    # окно размывается на кадре
    - process: "Telegram.exe"
    - domain: "mail.yandex.ru"
  viewNotice: onView       # уведомлять сотрудника о просмотре его снимков

telemetry:
  foregroundWindow: true
  idle: { threshold: 600s } # порог простоя — 10 минут
  processes: true
  usb: true

retention:                 # сроки хранения — из приказа
  screenshots: 90d
  events: 365d
```

## Запись события

Время в приложениях считается на сервере из потока событий:

```text
08:58:12  foreground  EXCEL.EXE   "Бюджет 2027.xlsx — Excel"
09:14:40  foreground  chrome.exe  "Задачи — Jira"   domain=jira.corp.local
09:31:05  idle_start  (нет ввода 600 с)
09:42:18  idle_end
```

Одно событие в хранилище:

```json
{
  "ts": "2026-11-26T09:14:40+05:00",
  "device_id": "WKS-1042",
  "kind": "foreground",
  "process": "chrome.exe",
  "title": "Задачи — Jira",
  "domain": "jira.corp.local",
  "state": "active"
}
```

## Окно сотрудника

По клику на значок в трее сотрудник видит окно «Что обо мне собирается»:

- **Что собирается:** снимок экрана раз в 5 минут и при смене окна; список запущенных программ; время в приложениях; подключение флешек.
- **Что не собирается:** нажатия клавиш, звук, камера, личные файлы.
- **Последние снимки:** миниатюры за сегодня — ровно те, что ушли на сервер, с размытием.
- **Пауза:** «Личное время» на 15/30/60 минут, если политика разрешает.
- **Документы:** положение о мониторинге и контакт ответственного.

## Лента дня и отчёты

**Лента дня.** Горизонтальная шкала рабочего дня: сегменты приложений с цветом по категории, отдельные цвета для простоя, паузы и нерабочего времени. Под шкалой — таблица сегментов (время, приложение, заголовок окна, домен, число кадров). Клик по миниатюре открывает снимок — с указанием причины и записью в журнал аудита.

**Отчёты:**

| Отчёт | Что показывает | Выгрузка |
|---|---|---|
| Время в приложениях | по группе и периоду, с категориями | CSV, XLSX |
| Табель | начало, конец, активное время по дням | XLSX, формат для 1С:ЗУП |
| Загрузка подразделения | распределение активного времени, переработки | XLSX |
| Инвентаризация ПО | программы, версии, число установок | CSV |
| Инвентаризация железа | ПК, процессор, память, диски, ОС, защита | CSV |
| USB и носители | подключения по ПК и людям | CSV |

## Правило и оповещение

Пример правила «из коробки»: подключение USB-накопителя вне белого списка.

```text
Условие:  событие usb_connected, serial НЕ в whitelist
Окно:     1 час
Порог:    1 срабатывание → уровень «низкий», оповещение
          50 за час      → уровень «высокий», карточка инцидента
Действие: оповещение в консоль и SIEM; предупреждение сотруднику без блокировки
```
