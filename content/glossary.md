Агент
: Программа на ПК сотрудника: служба, помощник, окно сотрудника и обновлятор.

Помощник (session helper)
: Процесс агента, работающий в сессии пользователя. Делает снимки и следит за окнами, потому что служба из сессии 0 рабочий стол не видит.

Сессия 0
: Изолированная сессия Windows, в которой работают службы. С Windows Vista она отделена от рабочего стола пользователя.

DXGI Desktop Duplication
: API Windows 8+ для получения кадров рабочего стола из видеопамяти, с информацией об изменённых областях.

Windows.Graphics.Capture (WGC)
: API Windows 10+ для захвата монитора или отдельного окна.

ETW
: Event Tracing for Windows — механизм трассировки событий ядра и приложений с низкими накладными расходами.

WMI
: Windows Management Instrumentation — интерфейс к сведениям о системе и железе.

Перцептивный хэш (pHash, dHash)
: Короткий отпечаток изображения, который почти не меняется при небольших изменениях картинки. Позволяет находить почти одинаковые кадры.

OCR
: Распознавание текста на изображении.

mTLS
: TLS с взаимной аутентификацией: и сервер, и клиент предъявляют сертификаты.

Политика
: YAML-документ с правилами сбора для группы ПК или пользователей. Подписывается и версионируется.

Цель обработки
: Утверждённая приказом цель, ради которой собираются данные. Ограничивает состав данных и сроки хранения.

Кольцо обновлений
: Группа ПК, получающая новую версию агента в определённом порядке: canary, early, broad.

Юридическое удержание
: Запрет удаления данных конкретного человека за период на время проверки или спора.

ЛНА
: Локальный нормативный акт работодателя (положение, правила, инструкция).

ПДн
: Персональные данные в смысле 152-ФЗ.

ИСПДн
: Информационная система персональных данных.

ADR
: Architecture Decision Record — запись архитектурного решения с контекстом и последствиями.
