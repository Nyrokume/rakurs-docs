## Требования и стек

| Часть | Среда и технологии |
|---|---|
| Агент | Windows 10 (22H2)/11 x64, Windows Server 2019/2022 с RDS; язык Go |
| Сервер | Linux в контуре организации, контейнеры; язык Go, один бинарник |
| Хранилище | PostgreSQL (метаданные, события, текст OCR, аудит) + S3-совместимое хранилище снимков |
| Распознавание текста | Tesseract (rus+eng) на сервере |
| Консоль | Веб-приложение (React + TypeScript), раздаётся сервером |
| Транспорт | gRPC поверх mTLS (агент→сервер), REST/JSON (консоль→сервер) |
| Интеграции | Active Directory, SIEM (syslog/CEF) |

## Развёртывание

- **Сервер** — `docker compose` в контуре организации: сервер, PostgreSQL, S3-хранилище. Для малых установок — одна виртуальная машина с локальным диском.
- **Агент** — пакет MSI, раскатывается через групповые политики (GPO), обновляется кольцами с возможностью отката.
- **Контур** — все данные остаются в инфраструктуре организации; агент сам инициирует соединения, на ПК нет открытых портов.

## Приватность и ограничения

- Мониторинг **открытый**: сотрудник уведомлён, есть локальный нормативный акт и подпись об ознакомлении; до подтверждения ознакомления данные с привязкой к человеку не собираются.
- Личные окна и приложения размываются или пропускаются **до сохранения** кадра.
- Данные автоматически удаляются по срокам хранения из политики; сотрудник может запросить выгрузку своих данных.
- Система **не собирает**: нажатия клавиш, содержимое буфера обмена, переписку, звук с микрофона и видео с камеры; не работает в скрытом режиме и не обходит антивирус.

**Вне объёма версии 1.0:** macOS и мобильные устройства, облачная SaaS-версия, онлайн-трансляция экрана, блокировка приложений и сайтов, интеграция с DLP-шлюзами, агент для Linux (версия 1.1).
