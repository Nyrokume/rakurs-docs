Остальные страницы описывают целевую систему. Здесь — то, что уже есть в коде версии 0.9 ([репозиторий](https://github.com/Nyrokume/yasnost)) и что работает прямо сейчас.

!!! note "Демо и продукт"
    [Демо консоли](https://nyrokume.github.io/yasnost/console-demo/) показывает вымышленные данные. Настоящая консоль входит в сервер: в ней пустая база, первичная настройка и реальные формы.

## Установка

Сервер ставится одной командой из офлайн-комплекта. Нужны Linux, Docker Engine и плагин compose.

```bash
tar xzf yasnost-0.9.0.tar.gz && cd yasnost-0.9.0
sudo ./yasnost-install --host yasnost.corp.local --org "ООО Ромашка"
```

Что делает скрипт:

1. Проверяет Docker, compose и свободное место.
2. Загружает образы из `yasnost-images.tar`: сервер, PostgreSQL 17, SeaweedFS.
3. Создаёт `/opt/yasnost/.env` со случайными паролями и одноразовым токеном первичной настройки.
4. Запускает `docker compose up -d` и ждёт ответа `/readyz`.
5. Выполняет проверки сервера (preflight) и показывает адрес консоли и токен настройки.

Повторный запуск обновляет установку и пароли не меняет. Чтобы разнести роли по отдельным контейнерам, добавьте `--split`: `gateway`, `api` и `worker-ocr` пойдут каждый в свой контейнер.

## Порты

| Порт | Что | Кто подключается |
|---|---|---|
| 8080 | консоль и REST API (HTTP; для HTTPS поставьте обратный прокси и `YASNOST_SECURE_COOKIES=1`) | браузеры администраторов и руководителей |
| 8443 | приём агентов, HTTPS с взаимной проверкой сертификатов (mTLS) | агенты на ПК |
| 5432, 8333 | PostgreSQL и S3 (SeaweedFS), только внутри compose | сервер |

## Подключение ПК

1. В консоли: «Отделы» → выбрать отдел → «Выпустить токен». Срок, лимит ПК и подпись задаются там же.
2. Консоль один раз показывает готовые команды для Windows, Linux и Ansible.
3. Агент сначала сверяет отпечаток сертификата сервера, затем регистрируется и получает свой сертификат. С этого момента ПК виден в «Компьютеры».

```bash
sudo yasnost-agent enroll --server https://yasnost.corp.local:8443 --token … --ca-sha256 … && sudo yasnost-agent install
```

На ПК агент показывает значок в трее и уведомление. В меню значка есть пункт «Что обо мне собирается» и пауза. Проверить установку: `yasnost-agent doctor`.

## API

Спецификация OpenAPI 3.1: [`server/api/openapi.json`](https://github.com/Nyrokume/yasnost/blob/main/server/api/openapi.json). Она генерируется из кода, а тест не даёт спецификации разойтись с маршрутами.

- Вход — сессия в cookie. Каждый запрос на изменение отправляется с заголовком `X-Yasnost-Csrf: 1`, активная роль — с заголовком `X-Yasnost-Role`.
- Открыть снимок, искать по тексту снимков, выгрузить табель и собрать архив данных можно только с причиной. Причина пишется в журнал, и сотрудник её видит.

## Отличия от целевой схемы

| В описании | В версии 0.9 |
|---|---|
| gRPC между агентом и шлюзом | HTTPS + mTLS, JSON |
| Отдельный nginx для консоли | консоль раздаёт сам сервер; TLS — на вашем обратном прокси |
| MSI, deb/rpm, каналы обновлений | один бинарник агента; установка командой, Ansible или GPO |
| macOS | агент собирается, но без сбора и значка |
| Wayland | не поддерживается: `doctor` предупреждает, сбора нет (нужен X11) |
| SSO/OIDC, почтовые уведомления | нет; вход по локальным учётным записям с 2FA или через AD |
